Fonction d'entrée `2d6b:0008` (745 octets) et son **rappel par image `2d6b:02f1`** (305 octets, lu dans `decomp/2d6b_02f1_fun.c` ; tables `CS:2d6b:0422` et `0434` lues dans l'exécutable). Code : `scenes/minigames/s30-bridge.ts` (`createBridge`, `BridgeScene`). Tests : `test/teleportaschtroumpf/minigames/s30-bridge.test.ts`. Confiance : **sûr** (déroulé, fenêtre, gains) ; **probable** pour le détail du dessin.

## Principe

Un seul clic de timing. La vidéo `s30a.mux` (130 images, 11/s, non passable : drapeaux `0x2080`, ni `0x400` ni `0x800`) montre le Schtroumpf qui s'approche d'un pont cassé ; le rappel lit le bouton (`DS:4BBD == 1`, Espace ou clic gauche) à chaque image décodée (`DS:3DED`). Le **niveau du joueur n'est jamais lu** : la difficulté est celle de la vidéo, identique aux trois niveaux. Seul l'indice de l'oiseau compte (`DS:6F37 == 0x1E` : remis à 0, `local_3 = 3`).

## Fenêtre de clic (image = `DS:3DED`)

| Image | Effet |
|---|---|
| < 0x34 | clic oublié (`DS:7C10` remis à 0), on peut recliquer |
| 0x34, 0x35, ≥ 0x3F | clic consommé sans effet : plus aucune tentative |
| 0x36 à 0x38 | saut puis **chute à l'eau** (`DS:9000 = 1`), 0 point |
| 0x39 à 0x3B | atterrit en (0x80, 0xAD) : 1 point (3 avec l'oiseau), voix `s30c003t` |
| 0x3C, 0x3D | atterrit en (0xB5, 0xA9) : 2 points (3 avec l'oiseau), voix `s30c002t` |
| 0x3E | atterrit en (0xF2, 0xA8) : 3 points, voix `s30c001t` |

Un clic dans la fenêtre arrête la vidéo (`DS:6337 = 1`) ; le sprite de saut (animation 0 de `s30c001s.hy8`, 6 images, une toutes les 5 centièmes) est posé en (`0x6A, 0x74, 0x7E, 0x88, 0x92, 0xA8, 0xBC, 0xCA, 0xE0` selon l'image, 0xA5) sur l'**image 0x35 de la vidéo** (copiée dans B par le rappel : `12ec:037c(A, B)`).
