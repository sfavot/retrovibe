# S33 « La Formule Magique »

Fonction d'entrée `1ceb:000c` (2 885 octets, appelée par `28a3:00ad` et `1a3c:002a`). Code : `scenes/minigames/s33-magic-formula.ts` (`createMagicFormula`, `MagicFormulaScene`). Tests : `test/teleportaschtroumpf/minigames/s33-magic-formula.test.ts`. Confiance : **sûr** pour les règles, les niveaux, les positions et la fin ; **probable** pour le fondu sonore et les sons courts (voir « Écarts »).

## Principe

Un Mastermind à trois emplacements. La formule secrète est de trois symboles tirés dans une liste de `N` symboles ; le joueur propose, le jeu répond par emplacement : bien placé (2), présent ailleurs (1), absent (0). Six essais, 120 secondes.

## Déroulé

1. Chargement : `s33a001d.mcg` (fond, fondu d'entrée), voix-bruitages `s33a001b` (déplacement), `s33a003b` (bien placé), `s33a004b` (autres), `s33a000s.hy8` (36 sprites de 64 × 16 : 12 symboles × 3 états, neutre / présent ailleurs / bien placé), `s33a001s.hy8` (6 sprites, une animation de 6 images : l'étincelle des réponses).
2. **Niveau** : `DS:6F37 == 0x21` (indice de l'oiseau sur S33) : remis à 0, niveau interne 3 ; sinon niveau du joueur. Table `CS:1ceb:0b51` (un mot par niveau) : niveau 0 → **6** symboles, 1 → **7**, 2 → **8**, 3 → **5**. Le tirage de la formule est refait en cas de doublon aux niveaux **0 et 3** seulement (`1ceb:02d1`).
3. **Liste** : un premier symbole `rand × 12 / 0x8000` (groupe de 3 sprites), puis sept autres par rejet (un `rand` par essai) : huit groupes différents parmi douze. Les `N` premiers sont dessinés à gauche (x 0x0B, y = 0x20 + 0x16 × i) et recopiés dans le fond.
4. **Formule** : trois fois `rand × N / 0x8000`, positions dans la liste.
5. **Boucle**, un pas tous les 5 ticks (`1f33:0348(5)`), chrono 2 démarré avant (`1f33:0181(2)`) :
   - haut / bas (`DS:4BBB` bits 1 / 2) : le curseur de liste se déplace, en boucle, et fixe le symbole de l'emplacement courant ; gauche / droite (bits 4 / 8) : change d'emplacement (0 à 2, sans boucle) et reprend le choix de celui-ci. Chaque déplacement joue `s33a001b` (`348d:0b42(2, ptr)`). Une touche tenue ne se répète qu'après 50 centièmes de seconde (verrou levé au relâchement ou à `+0x32`) ;
   - Espace / clic gauche (`DS:4BBD == 1`, hors animation) : la proposition est jugée (`1ceb:0522..0629`) : 2 pour chaque symbole bien placé (son `s33a003b`), puis pour chaque autre, 1 s'il existe à un autre emplacement de la formule non déjà apparié, 0 sinon (son `s33a004b`). Victoire si trois 2 ; échec si c'est le 6ᵉ essai sans victoire. Trois `rand × 3` règlent ensuite les délais de l'animation ;
   - animation (touches ignorées) : une étincelle sur les trois emplacements (anim. 0 de `s33a001s`, 6 images, à `y = 0x98 − 0x16 × (essai − 1)`, x 0x87 / 0xC8 / 0x109) ; à sa 3ᵉ image les trois symboles de la proposition apparaissent avec leur réponse (sprite = symbole + réponse, x 0x69 + 0x41 × i, `y = 0x8E − 0x16 × (essai − 1)`) ; chaque emplacement joue ensuite sa propre étincelle après un délai de 0 à 2 pas ; une fois les trois finies et deux pas passés, `13fc:067d` recopie la rangée et tout ce qui est dessous dans le fond et les touches reprennent ;
   - toujours dessinés : la proposition en cours (x 0x69 + 0x41 × i, y 0xB0) et deux cadres de couleur 5 (emplacement : `(0x69 + 0x41 c, 0xA0)–(0xA5 + 0x41 c, 0xB1)` ; liste : `(0x0B, 0x10 + 0x16 k)–(0x47, 0x21 + 0x16 k)`) ;
   - temps : `1f33:019a(2) > 0x78` donne l'échec (soit 121 s). La fin n'est prise qu'une fois l'animation terminée, la victoire l'emportant.
6. **Fin** : fondu sonore `1343:0037` (le volume descend de `DS:212` à 1, un cran toutes les 20 centièmes de seconde), son coupé. **Échec** : le fond est restauré et la formule est dessinée (état « bien placé ») sur la rangée de la proposition. Dans les deux cas, les voix `s33a` + (3 + `DS:18BC[symbole]`) des trois symboles de la formule, chacune attendue (`1f33:03a7`), fondu au noir, puis la vidéo par `154c:0954` (passable). **Victoire** : l'ingrédient 7 est donné (`1e52:0053`) et la vidéo est `s33c1` si l'ingrédient 7 est dans l'objectif (`1e52:0008(7)`), `s33c2` sinon (**l'inverse de S27 et S32**, lu dans le désassemblage `1ceb:0a79`). **Échec** : `s33b`.

## Bonus de l'oiseau (question ouverte 1 de `rules.md`)

Il met le niveau interne à 3 : **5 symboles sans répétition**, soit 60 formules possibles contre 120 (niveau 0), 343 (niveau 1) et 512 (niveau 2). C'est le niveau le plus facile, pour tous les joueurs. Sûr (table de sauts relue dans l'exécutable).

## Gain et issue

`MinigameOutcome` `{ kind: "ingredient", success }`, ingrédient 7 donné par `Game.resolveMinigame`. Mode libre : même scène, la carte reprend à la fin.

## Écarts et incertitudes

- Les sons courts (déplacement `s33a001b`, bien placé `s33a003b`, autre `s33a004b`) passent par le **canal de bruitage mélangé** (`348d:0b42(2, ptr)`, `voice.playEffect`, `engine.md` §5.2 bis) : la musique continue de jouer. Un seul emplacement : à une proposition, les trois sons s'enchaînent et **seul le dernier reste** (sûr). Les noms des symboles restent sur la voie. Pas d'écart.
- Fondu sonore : le niveau est restitué juste après, car les voix suivantes sont audibles dans l'original (restitution par le code appelant : hypothèse).
- La liste est dessinée après le fondu d'entrée (comme `13fc:0150(…, 1)` suivi du dessin).
- Le blocage de `1f33:036d` (attente du relâchement du bouton, 5 s au plus) après une proposition n'est pas reproduit : un nouvel appui est pris en compte (`justPressed`).
- La souris pousse contre les bords de l'écran dans l'original (`14b3:004c`) : non reproduit, clavier seul.
- Aucune copy visible : les voix et sprites viennent de l'original.
